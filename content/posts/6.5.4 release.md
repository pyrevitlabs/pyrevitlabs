# pyRevit 6.5.4

pyRevit 6.5.4 is out, and it's the last release on the 6.x line before 7.0.

This one wraps up the fixes that were sitting on develop, waiting to ship: settings saving properly on all-users installs, output window flush fixes, a new Filter Legend tool, Keynote Manager stability work, icon theme switching without needing a Revit restart, and a handful of CLI and core library improvements.

7.0 is where the bigger shift happens. It picks up the C# loader refactoring work and starts dropping support for older Python patterns as part of that transition, along with dropping Revit <2021. We kept that off 6.5.4 on purpose so this release stays a clean, low-risk hotfix before the bigger changes land.

If you're on pyRevit, worth grabbing 6.5.4 now and keeping an eye out for 7.0 notes as they come.

Release notes and downloads here: https://github.com/pyrevitlabs/pyRevit/releases/tag/v6.5.4.26228%2B1146
